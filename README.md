# 猫娘助手

TIM / QQ 的 Xposed 增强模块，基于 LSPosed 框架。

面向个人使用的本地模块，不含埋点、不含崩溃上报、不含统计 SDK。

网络请求的去向见下方「对外网络请求」一节。

> **本仓库仅供学习与技术交流使用，请勿用于任何商业用途或违法用途。**

---

## 功能

### 主页一览

模块主界面是控制台，从上到下：

| 区块 | 内容 |
|---|---|
| 核心服务 | 无障碍服务状态、LSPosed 状态、总开关、悬浮窗转换 |
| 聚合中心 | 进入各功能页（见下表） |
| GitHub 仓库 | 一键跳转本仓库 |
| 下载管理 | 所有下载任务的统一入口 |
| 实时预览 | 输入一句话，本地预览猫娘化效果 |
| 设备信息 | 当前宿主版本、作用域、模块版本 |

聚合中心里的入口：

| 入口 | 主要内容 |
|---|---|
| 聊天功能 | 防撤回、复读、闪照破解、改本地文本、文字表情复合等 |
| 群管理 | 群主快捷菜单、群成员管理、群打卡 |
| 去除限制 | 转发 / 拍一拍上限、多选撤回、去 QQ 浏览器、异常资料卡、卡片点击限制 |
| 解析功能 | 音乐与视频链接解析、转文件 / 转语音 |
| 文件功能 | 上传 APK 自动改名等 |
| 伪造功能 | 伪装网络状态、自定义设备信息、伪造手机号、伪造客户端版本 |
| 红包功能 | 手动打开、自动领取、规则设置 |
| Hook 功能 | 长按提取、发送与协议、自动抓取消息、抓取记录 |
| 功能状态 | 体检面板，看哪些 Hook 没挂上 |
| 防检测 | 掐断崩溃与统计上报 |
| 配置备份 | 导出 / 导入配置 |
| 加入交流群 | 一键加入反馈群 |

| 功能 | 说明 |

### 消息时间与发送者版本

| 功能 | 说明 |
|---|---|
| 显示消息时间 | 每条消息下方显示收到时间，颜色 / 深浅 / 字号 / 四种格式可调 |
| 显示发送者版本 | 在时间后面显示对方用的 QQ / TIM 版本号 |
| 版本排版 | 同行 / 版本在上 / 时间在上 三种排法 |
| 版本字号 | 版本号单独调字号，不受时间字号影响 |
| 渠道推测 | 按 subId 与版本基准的差值推测下载渠道（应用宝 / vivo / 荣耀 / 小米 / OPPO / 豌豆荚 / 应用汇），会标注「推测」 |
| 长按手动标注 | 遇到认不出的版本，长按消息填写版本和渠道，同一 SubId 全部生效 |

**版本号是怎么来的**：QQ 消息协议里带的是 `subAppId`（一串数字，随版本变化），
需要靠 `app/assets/sender_version.json` 反查成版本号。这个表随 QQ 更新会滞后，
所以提供了「长按手动标注」作为兜底。

数据来源见 [NOTICE.md](NOTICE.md)。

### 去除限制

| 功能 | 说明 |
|---|---|
| 去除转发限制 | 解除转发时的人数上限 |
| 去除拍一拍限制 | 拍一拍不再有 10 秒冷却 |
| 多选撤回 | 长按进多选，批量撤回自己的消息 |
| 去你大爷的 QQ 浏览器 | 网页一律交给系统浏览器打开 |
| 允许查看异常资料卡 | 忽略账号异常状态（201 / 202），正常查看资料卡 |
| 语音消息自动转文字 | 打开 TIM 的语音转文字，AI 才能听懂语音 |
| 绕过 TIM 卡片点击限制 | 解除 TIM 中部分卡片（小程序 / 游戏中心 / 第三方分享卡）无法点击的问题 |

> 「绕过卡片点击限制」的做法是让 TIM 的 ark 白名单判定恒为通过。
> 卡片能否真正打开仍由 TIM 自己的 ark 容器决定，个别卡片可能白屏。

## 安装

1. 安装 APK
2. 在 **LSPosed** 中启用本模块
3. 作用域勾选 **TIM**（`com.tencent.tim`）
4. 强制停止 TIM 后重新打开

> 本模块是 Xposed 模块，单纯安装不会出现独立功能界面。
> 需要 Root + LSPosed 环境。

---

## 构建

需要 JDK 11 与 Android SDK 构建工具（aapt2 / d8 / apksigner）。

```bash
sh 构建APK.sh            # 完整构建
sh 构建APK.sh --clean    # 清理后构建
sh 构建APK.sh --java     # 只编译 Java
```

构建配置在 `toolchain.env`（路径、版本、签名信息）。
`toolchain.env` 含签名密码，**不要提交**。

### 目录结构

```

│   ├── com/cathelperawa/owo/app/    本项目代码
```

## 权限

| 权限 | 用途 |
|---|---|
| `INTERNET` | 更新检测、解析、网盘、AI 等功能联网 |
| `SYSTEM_ALERT_WINDOW` | 悬浮球 / 悬浮窗 |
| `POST_NOTIFICATIONS` | 下载进度通知 |
| `FOREGROUND_SERVICE`（含 `DATA_SYNC` / `MEDIA_PLAYBACK`） | 下载与音频播放保活 |
| `WAKE_LOCK` | 下载过程防止休眠中断 |
| `WRITE_EXTERNAL_STORAGE`（仅 Android 9 及以下） | 保存下载文件 |
| `REQUEST_INSTALL_PACKAGES` | 下载完成后拉起安装器 |
| `BIND_ACCESSIBILITY_SERVICE`（`QQAccessibilityService`） | **非 Root 环境**下悬浮球自动改写输入框文字的兜底通道 |

关于无障碍服务：模块本身是 Xposed 模块，正常使用时**不需要开启无障碍**，核心功能全部走 LSPosed Hook。
只有在「免 Root / 悬浮球模式」下需要自动改文字时才会用到它，届时系统会弹出授权提示，用户可自行决定是否开启。
在 LSPosed 环境下不开启该权限，功能不受任何影响。

不读通讯录、不读短信、不申请定位、不申请通话记录、不读取剪贴板以外的任何个人数据。

## 对外网络请求

外部域名共 71 个，按用途分六类：

| 类别 | 用途 |
|---|---|
| 腾讯自有 | 头像、表情、聊天图片 |
| 内容平台（B站 / 抖音 / 快手 / 小红书 / Pixiv） | 分享链接解析成直链 |
| 音乐（网易云 / 酷狗 / 酷我） | 搜歌、取播放地址 |
| 网盘（百度 / 夸克 / UC / 迅雷 / 139 / 123 / 蓝奏 / 115） | 目录、分享、下载 |
| AI（OpenAI / DeepSeek / Brave / Tavily / Serper） | 需自填 Key，不填不发请求 |
| 图床与语音（freeimage / uguu / 百度 TTS） | 图片外链、文字转语音 |

只有主动使用这些功能时，相应内容才会发给对应服务；不开则不会有内容离开设备。

代码里没有埋点、没有崩溃上报、没有统计 SDK。

## 其他

- **不收集**设备信息（IMEI / MAC / 序列号一概不读）；「自定义设备信息」功能是**伪造**给宿主看的，方向相反
- **不主动上传**聊天内容；只有你开启 AI 回复 / 联网搜索 / 语音合成时，相应文本才会发给对应的第三方服务
- 无账号体系、无统计、无广告、无内购
- 配置文件导出时会过滤 `uin / uid / token / cookie / password / skey / guid / imei / mac` 等字段
