# 猫娘助手

TIM / QQ 的 Xposed 增强模块，基于 LSPosed 框架。

面向个人使用的本地模块，不联网、不上传、不收集任何数据。

---

## 功能

### 聊天增强

| 功能 | 说明 |
|---|---|
| 防撤回 | 拦截撤回指令并提示 |
| 长按复读 | 长按消息出现「复读」按钮 |
| 自定义点数 | 发骰子 / 猜拳时自选结果 |
| 表情看图 | 以图片的方式打开表情 |
| 闪照破解 | 以图片的方式打开闪照 |
| 改本地文本 | 长按消息改显示文本（仅本地生效） |
| 去除回复自动艾特 | 回复消息时不再自动 @ 对方 |
| 显示艾特对象 | 群聊里把 @ 的对象显示出来 |
| 文字表情复合消息 | 文字和表情可以一起发 |

### 猫娘化引擎

把发送前的文字自动转换成猫娘语气。

| 开关 | 说明 |
|---|---|
| 总开关 | 猫娘化功能的全局开关 |
| 基础猫娘化 | 核心转换 |
| 撒娇模式 | 语气增强 |
| 结尾加喵 | 句尾追加「喵」 |
| 加颜文字 | 自动追加颜文字 |
| 随机卖萌 | 随机插入萌系表达 |
| 波浪号 | 标点替换为「~」 |
| 称呼替换 | 自定义称呼映射 |
| 主人称呼 | 对特定对象的称呼 |

### 其他

- 多选转发
- 拍一拍增强
- 本地消息导出
- 内置 Web 控制台页面

## 安装

1. 安装 APK
2. 在 **LSPosed** 中启用本模块
3. 作用域勾选 **TIM**（`com.tencent.tim`）
4. 强制停止 TIM 后重新打开

> 本模块是 Xposed 模块，单纯安装不会出现独立功能界面。
> 需要 Root + LSPosed 环境。

---

## 构建

需要 JDK 11 与 Android SDK 构建工具（aapt2 / d8 / apksigner）。

```bash
sh 构建APK.sh            # 完整构建
sh 构建APK.sh --clean    # 清理后构建
sh 构建APK.sh --java     # 只编译 Java
```

构建配置在 `toolchain.env`（路径、版本、签名信息）。
`toolchain.env` 含签名密码，**不要提交**。

### 目录结构

```
app/
├── AndroidManifest.xml
├── java/                源码
│   ├── com/cathelperawa/owo/app/    本项目代码
│   └── top/artmoe/inao/entries/     第三方 protobuf 生成类（见 NOTICE.md）
├── res/                 布局、图标、样式
├── assets/
│   ├── xposed_init      Xposed 入口声明
│   └── console/         控制台资源
│       └── assets/      界面插画（被 Images.java 引用）
└── proto/               上游 proto 定义（来源证明）
```

> 说明：`assets/console/` 下的 `index.html` / `style.css` / `app.js` 是控制台早期的
> Web 原型设计稿，**当前版本的原生 UI 并未加载它们**，保留仅供设计参考。

## 隐私

本模块**不含任何数据上传逻辑**，权限只有一个 `SYSTEM_ALERT_WINDOW`（悬浮窗）。

### 对外网络请求

共三处，全部是只读 **GET 下载**，不携带账号凭证，不上传用户数据：

| 目标 | 用途 |
|---|---|
| `q1.qlogo.cn` | 拉取 QQ 头像用于界面显示 |
| `multimedia.nt.qq.com.cn` | 下载聊天图片 |
| `fanyi.baidu.com/gettts` | 文字转语音（TTS） |

> ⚠️ **请注意**：使用「文字转语音」功能时，待转换的文字会作为 URL 参数发送给百度。
> 不使用该功能则不会有任何内容离开设备。代码中不存在 `POST` / `setDoOutput` 之类上传逻辑。

### 其他

- 不收集设备信息
- 不上传聊天内容
- 无账号体系、无统计、无广告
- 配置文件导出时会过滤 `uin / uid / token / cookie / password / skey / guid / imei / mac`
