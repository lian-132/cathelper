────────────────────────────────
目录说明
────────────────────────────────
app/                源码根
  AndroidManifest.xml
  java/             源码
  res/              布局、图片、颜色
  assets/           内嵌资源
构建APK.sh          一键构建脚本

未包含（体积或安全原因）：
  build/            构建产物，可重新生成
  toolchain/        aapt2 / d8 / apksigner 等工具链
  toolchain.env     工具链路径与签名配置
  密钥/             签名密钥，不随源码分发

────────────────────────────────
构建方式
────────────────────────────────
1) 准备 JDK 11、Android SDK 的 android.jar、d8、apksigner
2) 写一份自己的 toolchain.env（路径 + 自己的签名信息）
3) sh 构建APK.sh
